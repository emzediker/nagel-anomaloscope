How to use it
  1. Select an observer type.
  2. Adjust the mixture field and test-field radiance.
  3. Ask students to find the matching point/range.
  4. Compare their result with the expected Nagel pattern.

Teaching reference: normal ≈ 45/17; deuteranopia can match across 0–73 at ≈17; protanopia can match across 0–73 with test radiance changing from roughly 35 toward 5; deuteranomaly favors 0–45; protanomaly favors 45–73.

This is a visual teaching approximation. Computer screens cannot reproduce the actual monochromatic 546-, 590-, and 670-nm stimuli of a calibrated clinical anomaloscope.
